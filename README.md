# Bottons · Edyllana

Site estático (pronto para GitHub Pages).

## Páginas
- `index.html` — página inicial (hero + chamada para pedido)
- `catalogo.html` — portfólio, acabamentos, photocards e favoritos
- `pedido.html` — montador de pedido (bottons + photocards), carrinho, cupom e envio via WhatsApp

## Assets
- `styles.css`, `script.js` — compartilhados entre as páginas
- `assets/` — coloque aqui as fotos dos produtos (o site usa placeholders online até você trocar os links `IMG_*` no topo do `script.js`)
- `precos-photocards.png` — imagem de referência da tabela de preços

## Publicar no GitHub Pages
1. Suba a pasta como repositório
2. Settings → Pages → Deploy from branch → `main` / `/ (root)`
3. Acesse a URL gerada
